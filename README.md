# voip-network-configuration
cisco packet tracer voip network with four ip phones
The network consists of: 1 Cisco router, 1 Cisco 2960 switch and 4 Cisco 7960 IP phones
Configurations Implemented: Router and switch connectivity, IP addressing and DHCP, as configured, IP phone configuration and extensions and VoIP communication between phones
Testing and Results : Verified network connectivity, Checked IP phone registration, Tested calls between configured IP phones and Confirmed that calls worked successfully.
Tools Used : Cisco Packet Tracer and Cisco IOS CLI
